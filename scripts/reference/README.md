# Reference workflows

Scripts are grouped by purpose and dataset, with duplicate directory wrappers removed. They are retained research records, not a unified executable application. Read path settings and imports before running them; do not batch-run this folder. Missing data and checkpoints must be supplied separately.

For the reusable model see `src/models/proposed.py`; for portable preprocessing/augmentation use `scripts/prepare_data.py`. Detailed source provenance and all superseded versions remain in the complete local archive.
